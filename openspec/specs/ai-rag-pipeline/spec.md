# AI RAG Pipeline Specification

## Purpose

Grounds every user-facing answer EXCLUSIVELY in curated clinical documents via pgvector (HNSW) retrieval, GPT-4o (temperature 0) generation, and a mandatory coherence gate (cosine similarity + NLI + role-deviation guardrail) before any emission. GPT-4o-mini handles NLI, risk classification, and sentiment. Every vector row carries chunk metadata (category, source, language, legal framework).

## Requirements

### Requirement: REQ-RAG-1 — RAG-only generation at temperature 0

All user-facing answers MUST be generated by GPT-4o at temperature 0 using ONLY retrieved chunks as context; free-form knowledge MUST NOT be used; the system MUST NOT diagnose, prescribe, or recommend medication (standard refusal for medication queries).

#### Scenario: Grounded Q&A

- GIVEN a user question within scope
- WHEN chunks are retrieved and passed as context
- THEN GPT-4o generates at temperature 0 from those chunks only
- AND the answer is not emitted until the coherence gate passes

#### Scenario: Medication query

- GIVEN a user asks about medication dosage or adjustment
- WHEN the role-deviation guardrail flags the intent
- THEN the standard refusal is emitted
- AND no medication-related content is generated

### Requirement: REQ-RAG-2 — pgvector HNSW retrieval

Vector retrieval MUST use pgvector with an HNSW index on the embedding column; queries MUST use parameterized SQL; missing indexes MUST NOT be served silently.

#### Scenario: Retrieval over HNSW

- GIVEN a query embedding
- WHEN the retrieval runs
- THEN results are returned via the HNSW index
- AND the top-k chunks with metadata are returned

### Requirement: REQ-RAG-3 — Chunk metadata on every vector row

Every vector row MUST carry category, source, language, and legal framework metadata; retrieval results MUST expose these fields for the supervisor dashboard.

#### Scenario: Metadata-attributed retrieval

- GIVEN a retrieved chunk
- WHEN it is returned to the pipeline
- THEN category, source, language, and legal framework are attached
- AND the source trace is available for dashboard review

### Requirement: REQ-RAG-4 — Coherence gate before emission

The pipeline MUST NOT emit an answer unless it passes the gate: cosine similarity ≥ 0.85 → emit; 0.75–0.85 → retry once, then yellow-flag for review; < 0.75 or NLI contradiction → orange-block with NO emission and human review.

#### Scenario: Gate pass

- GIVEN a generated answer with cosine ≥ 0.85 and no NLI contradiction
- WHEN the gate evaluates
- THEN the answer is emitted
- AND the pass is logged

#### Scenario: Gate fail — orange block

- GIVEN a generated answer with cosine < 0.75 or an NLI contradiction
- WHEN the gate evaluates
- THEN the answer is NOT emitted
- AND an orange alert is raised for human review

#### Scenario: Gate borderline — yellow

- GIVEN an answer with cosine between 0.75 and 0.85
- WHEN the gate evaluates
- THEN the pipeline retries generation once
- AND if still borderline, the answer is yellow-flagged for review

### Requirement: REQ-RAG-5 — NLI contradiction check

An NLI check with GPT-4o-mini MUST run before emission; a contradiction verdict MUST block emission regardless of cosine similarity.

#### Scenario: NLI contradiction

- GIVEN an answer with high cosine but NLI contradiction verdict
- WHEN the NLI check completes
- THEN emission is blocked
- AND the result is routed as orange

### Requirement: REQ-RAG-6 — Role-deviation output guardrail

The output layer MUST block role-deviation terms (`diagnóstico`, `receto`, `padeces`, drug/dose terms) and MUST orange-block the output; borderline wording MUST be yellow-flagged.

#### Scenario: Deviation term blocked

- GIVEN a generated answer containing a role-deviation term
- WHEN the guardrail scans the output
- THEN the emission is blocked
- AND an orange alert is raised

### Requirement: REQ-RAG-7 — Side-tasks on GPT-4o-mini

Risk classification, NLI, and sentiment MUST be performed by GPT-4o-mini; the main conversational generation MUST remain on GPT-4o at temperature 0.

#### Scenario: Risk classification before retrieval

- GIVEN an incoming user message
- WHEN the pipeline starts
- THEN GPT-4o-mini classifies risk level (red/orange/yellow/normal)
- AND the classification drives routing before generation

### Requirement: REQ-RAG-8 — Source and trace metadata for dashboard

Every validated answer MUST return its source chunks and gate results as trace metadata consumable by the supervisor dashboard.

#### Scenario: Trace available on review

- GIVEN an orange-blocked or yellow-flagged output
- WHEN the supervisor opens the review
- THEN the exact chunks and gate scores that grounded (or failed) the answer are shown
